# Benchmark I — verifiable 1/sqrt(x) phasing circuit (invsqrt)

## What to build

A kickmix circuit with a single named register `x` of 22 qubits (little-endian)
plus any number of scratch qubits. For every integer x in [1, 3133452] it must
implement

    |x>|0...0>  ->  exp(2*pi*i/sqrt(x)) |x>|0...0>

with the phase (in turns) within 2^-24 / sqrt(x) of 1/sqrt(x). The `x`
register must be restored and every scratch qubit must return to |0>.

Your program (`artifact/program.py`) must define `build_circuit() -> km.Circuit`
for the benchmark instance (n_p = 10) and support
`python program.py OUTPUT.kmb` to write the circuit. Everything between the
EVOLVE-BLOCK markers in the baseline is yours to rewrite — the algorithm, the
precision parameters, the register layout — as long as the contract holds.

## Cost (minimize; lower is better)

    score = Q * (Toffolis + T / 4)

- Q = total qubit count of the circuit.
- Toffolis = MEAN Toffoli-like gates (CCX/CCZ/CSWAP) EXECUTED PER SHOT over
  64 shots of every x. A data-dependent circuit that skips work on easy inputs
  lowers the mean (e.g. test-and-skip against the per-x tolerance is legal).
- T gates cost 1 T each; non-Clifford Z-rotation angles cost
  `0.56 * log2(1/eps) + 5.3` T each, with eps auto-chosen to just fit the
  remaining phase tolerance (more rotations with less slack => pricier).
  Clifford angles are free.

Improvement is measured relative to the reference Newton-Raphson circuit
(Q=260, mean 7735 Toffolis + 37 rotations => combined_score 1.0).

## How it is verified (read this carefully)

The verifier simulates EVERY x in [1, 3133452] 64 times: inputs restored,
scratch clean, phase within tolerance — no sampled test set, so partial or
test-fitted correctness cannot pass. Measurement-outcome seeds are derived
from a cryptographic hash of your circuit bytes plus a fresh random salt per
evaluation: a circuit is only correct if it passes for all measurement
outcomes, not lucky ones. Keep margin: the reference tops out at ~48% of the
tolerance; synthesis error of rotations consumes the rest automatically.

## Allowed and encouraged

- Measurement-based uncomputation: `init_and` computes an AND into a clean
  qubit, `del_and` removes it for free (a measurement + phase fixup); it
  halves the cost of every temporary.
- Reversible fixed-point arithmetic of any design: shifts, truncated
  multipliers, tables/QROM via gf2 operations, unary-controlled shifts.
- Fewer Newton-Raphson steps, better initial guesses, fewer/cheaper rotations,
  data-dependent shortcuts, smaller scratch — every axis multiplies.
- The baseline's `fixed_point_model` is a fast classical bit-exact model of
  the reference pipeline; adapt it (or write your own) to check designs in
  milliseconds instead of building circuits.
